# Issue Tracker: Local Markdown

Issues and PRDs for this repo live as markdown files in `docs/planning`.

## Conventions

- PRDs live in `docs/planning`.
- Implementation issues live in `docs/planning/issues`.
- Triage state is recorded as a `Status:` line near the top of each issue file.
- Comments and conversation history append to the bottom of the file under a `## Comments` heading.

## When a Skill Says "Publish to the Issue Tracker"

Create a new markdown file under `docs/planning`, or under `docs/planning/issues` for implementation issues.

## When a Skill Says "Fetch the Relevant Ticket"

Read the file at the referenced path. The user will normally pass the path directly.
