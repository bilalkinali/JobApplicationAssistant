Status: done
Type: AFK

## Parent

## What to build

Tighten the Milestone 2 frontend so profile evidence, application list, and application detail work feel like separate parts of one workflow. This is a small cleanup slice after the core manual workflow pieces are in place.

This slice should not introduce new backend capabilities unless needed to complete the UI cleanup.

## Acceptance criteria

- [x] Navigation labels and section headings reflect the manual workflow clearly.
- [x] Profile contact details and profile facts are visually distinct.
- [x] Application list and application detail states are visually distinct.
- [x] Buttons and form actions use consistent wording across Profile and Applications.
- [x] Empty states guide the user toward the next manual action.
- [x] No AI, export, or diagnostics UI is introduced.
